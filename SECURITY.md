# Security policy

Please do not disclose a suspected vulnerability in a public issue. Send
a concise report to `yeshaowen2119@gmail.com`, including the affected
package version, operating system, reproduction steps, and potential
impact. Use non-sensitive example data and do not send access tokens or
confidential research records.

Security support applies to the current release. Scientific
disagreements, analysis-design questions, and ordinary software bugs
should follow
[SUPPORT.md](https://shaowen-ye.github.io/SOMevidence/SUPPORT.md).
