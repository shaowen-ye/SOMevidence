# Support

## Questions and bug reports

Use [GitHub Issues](https://github.com/shaowen-ye/SOMevidence/issues)
for reproducible software questions and bug reports. Before opening an
issue, please update to the current release and search existing issues.

A useful report includes:

- a minimal reproducible example with non-sensitive data;
- the complete error or warning message;
- `packageVersion("SOMevidence")` and
  [`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html);
- the preprocessing, resampling, and SOM specifications;
- whether optional packages such as `mclust`, `future`, `ggplot2`, or
  `shiny` are installed; and
- the expected and observed behavior.

Do not post confidential data, personal information, access tokens, or
unpublished coordinates in a public issue.

## Scope of support

The maintainer can investigate reproducible package behavior and
documentation problems. Package support cannot determine an appropriate
sampling unit, candidate number of classes, ecological label, or
decision threshold without study-specific evidence. A successful package
run is not validation of a scientific conclusion.

## Sensitive reports

Do not disclose a suspected security issue publicly. Contact the
maintainer at `yeshaowen2119@gmail.com` with a concise description and a
reproducible example that contains no sensitive research data.
